# Beaterista

Seu estúdio na palma da mão: app pessoal da Bea (alunos, aulas, estudos, Beat Lab, Estúdio de Ouvido e Feed).

- Site: https://beatrizmarquex2-art.github.io/beateristapp-/
- App estático (HTML, CSS e JS, sem build). Os dados ficam no Supabase, protegidos por login e RLS; nada pessoal fica neste repositório.
- `_headers` é usado só se o app for publicado no Netlify; no GitHub Pages vale a política de segurança que está no `index.html`.

- Passagem de bastão para sessões novas: veja `PASSAGEM.md`.
